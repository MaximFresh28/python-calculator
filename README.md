# Калькулятор

Консольный калькулятор на чистом Python с собственным парсером выражений. Без `eval()` и сторонних библиотек.

```
› 2 + 2 * 2
= 6
› f(x) = x^2 + 1
Функция определена: f(x) = x^2 + 1
› f(3) + 2pi
= 16.2831853072
› *2
= 32.5663706144
› 2 + * 3
      ^
Ошибка: Неожиданный символ «*»
```

## Возможности

- Правильные приоритеты: `2^3^2 = 512` (степень правоассоциативна), `-2^2 = -4`
- Неявное умножение: `2pi`, `3(1+2)`, `(1+2)(3+4)`, `2x`
- Переменные (`x = 5`), последний результат `ans`, продолжение вычислений: строка `*2` означает `ans*2`
- Пользовательские функции: `f(x) = x^2 + 1`, `dist(a, b) = sqrt(a^2 + b^2)`
- Точная целочисленная арифметика: `2^100` и `100!` считаются без потери точности, `6/3` даёт `2`, а не `2.0`
- Числа: `1.5`, `.5`, `1e-3`, `1_000_000`, `0xFF`, `0b1010`, `0o17`; символы `π`, `×`, `÷`
- 30+ функций: тригонометрия (с режимом градусов), логарифмы, корни, `gcd`, `lcm`, `comb`, `perm`, `min`, `max`, `avg` и другие
- Понятные ошибки на русском со стрелкой под проблемным местом
- Защита от «подвисания»: `9^9^9` или `5000!` отклоняются сразу, а не считаются минутами

## Запуск

Нужен Python 3.9+.

```bash
python calc.py              # интерактивный режим
python calc.py "sqrt(2)"    # одно выражение, код возврата 1 при ошибке
```

Команды: `:help`, `:deg` / `:rad`, `:vars`, `:funcs`, `:history`, `:clear`, `:q`.

## Как устроено

Выражение проходит три стадии:

```
"2 + 3x"  →  лексер  →  [NUM 2] [OP +] [NUM 3] [NAME x]
          →  парсер  →  BinOp(+, Num 2, BinOp(*, Num 3, Name x))
          →  вычислитель обходит дерево
```

**Лексер** разбивает строку на токены и запоминает позицию каждого. По этим позициям строится стрелка под ошибкой.

**Парсер** работает методом рекурсивного спуска: на каждый уровень приоритета своя функция (`expr` → `term` → `unary` → `power` → `postfix` → `primary`). Приоритет задаётся порядком вызовов, а не таблицей.

**Вычислитель** обходит дерево. Встроенные и пользовательские функции, переменные и константы разрешаются в момент вычисления, поэтому функция видит актуальные значения глобальных переменных.

Почему не `eval()`: он выполнит любой код Python, включая `__import__('os').system(...)`. Собственный парсер понимает только арифметику. В тестах это проверяется отдельно.
